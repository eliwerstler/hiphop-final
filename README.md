# Hip Hop Final Portfolio

A static website for a group final project in a Columbia hip hop course. There's a page for each team member's portfolio (`eli.html`, `jack.html`, `noah.html`, `riley.html`) and a shared playlist player.

The audio files aren't included in this repo because they're commercial recordings. To use the player locally, put your own copies in `playlist/` with the file names listed in `player.js`.

Open `index.html` in a browser to view the site.
